# Schulplaner

A personal school planner, built as a Progressive Web App (PWA). It runs in the browser,
can be added to the home screen and works offline.

## Private use

The app is hosted by me for my own private use. The code is public so it can be read,
but the hosted app is not a service for others: there are no public sign-ups and no support.

Please don't open issues asking for access or features.

## Built with AI

This project was made with the help of AI (Claude by Anthropic).
The code was written step by step together with the AI and checked by me.

## Tech

- React, TypeScript, Vite
- vite-plugin-pwa for offline support
- Dexie (IndexedDB) for local data
- Supabase for sync and sign-in

Setup notes (in German) are in [ANLEITUNG.md](ANLEITUNG.md).
